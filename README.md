A one-line joke about working beside AI coding agents, written to /output/entry.txt by a small deterministic TypeScript program.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes one fixed joke to /output/entry.txt (UTF-8, one line, 106 characters) and does nothing else — no network, no dependencies, same output on every run.
